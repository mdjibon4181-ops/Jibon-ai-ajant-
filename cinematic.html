বাস্তবধর্মী cinematic ছবি তৈরি করুন

দুটি reference থেকে একটি AI image generate করুন। AI-র লেখা ভুল হতে পারে, তাই image-এ text দেওয়া হয় না; নির্ভুল বাংলা/English typography পরের ধাপে যোগ করুন।

AI generation-এর জন্য server-এ OPENAI_API_KEY সেট থাকতে হবে। API key browser-এ দেওয়া যাবে না।

১ · একই ব্যক্তির দুইটি reference

শুধু নিজের বা ব্যবহারের অনুমতি থাকা ছবি দিন · JPEG, PNG, WebP · সর্বোচ্চ 10 MB করে

২ · Scene ও generation setting

মুখের পরিচয়ে close-up এবং পোশাক/ভঙ্গিতে full-body ছবিকে অগ্রাধিকার দিয়ে prompt তৈরি হবে। ছবিতে কোনো text বা watermark যোগ করা হবে না।

Provider-এর supported sizes সীমিত: 9:20, 9:16 ও 4:5-এর জন্য portrait 1024×1536; 1:1-এর জন্য 1024×1024; 16:9-এর জন্য landscape 1536×1024। এগুলো native 1440×3200 নয় এবং crop হতে পারে।

গোপনীয়তা ও provider

Generate করলে browser-এ বাছсан reference images server-এ পাঠানো হয়, সেখান থেকে OpenAI Images API-তে image editing request হিসেবে যায়। Server request content log করে না; provider-এর retention ও processing শর্ত প্রযোজ্য। কোনো retention/deletion নিশ্চয়তা দেওয়া হচ্ছে না। API ব্যবহার বিলযোগ্য হতে পারে; free tier ধরে নেওয়া যাবে না।
